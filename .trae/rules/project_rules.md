# 项目硬规则
只挡红线。细节看对应 SDD；怎么合作看根目录 AGENTS.md。

## 开工前
每个新任务开始，先完整读一遍根目录 `AGENTS.md`（协作流程、文档顺序、交付要求）和本文件，再动手。

## 技术栈
- 前端：React + Vite + TypeScript
- 后端：FastAPI 单服务
- 算法：LangGraph
- 不要另起一套栈

## 三条边界
- 算法不直连库；查数经后端
- 无行业字典也要能跑；字典/模板/示例是增强不是入场券
- 已存报表再打开只读快照，不重查、不重跑算法

## 存储与模型
- 数据：PostgreSQL（本地 Docker；生产推荐 Supabase）
- LLM / Embedding：商业化 OpenAI 兼容 API，环境变量配置；不绑厂商、不本地部署模型
- 不要另起与 SDD 冲突的存法

## 明确不做
完整登录权限中台、从零搭仪表盘、归因预测、上 K8s。
