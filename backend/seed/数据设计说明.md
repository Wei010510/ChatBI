## 二、转化漏斗口径

- **下单转化率** = `dwd_order` 下单量（order_status ≠ 'cancelled'）÷ `dwd_exposure_daily.exposure_count`
- **支付转化率** = `dwd_payment` 支付量（pay_status='success'）÷ `dwd_order` 下单量
- **GMV** = `dwd_payment` 中 pay_status='success' 的 `pay_amount` 合计
- **AOV** = GMV ÷ 支付笔数

## 三、关键分布

### 订单量按天趋势（day_factor）
- 2026 大促期(6/16~18)：×5.5（峰值）
- 2026 预热期(6/1~15)：×2.2
- 2026 后一周(6/19~25)：×1.6
- 2025 大促同期(6/16~18)：×3.8（低于今年 → 同比正增长）
- 平日：×1.0

### 渠道占比（大促期 GMV，从 dwd_payment 算）
| 渠道 | GMV | 下单转化率 | 支付转化率 |
| :--- | ---: | ---: | ---: |
| mini_app | 27.9 万 | 3.59% | 86.8% |
| app | 27.2 万 | 4.32% | 92.8% |
| offline | 12.7 万 | 7.74% | 91.4% |
| web | 8.5 万 | 1.27%（最低） | 83.3% |

> web 渠道曝光倍率设为 70（其他 12~28），人为压低下单转化率（C03「掉得最多」）。

### 广告效率与成本利润（大促期）
| 指标 | 数值 | 说明 |
| :--- | ---: | :--- |
| 广告花费 | 8.2 万 | `dwd_ad_daily.ad_spend` |
| 广告 GMV | 38.2 万 | `dwd_ad_daily.ad_gmv` |
| 自然流量 GMV | 38.2 万 | 总 GMV − 广告 GMV |
| ACOS | 21.5% | 广告花费 / 广告 GMV |

### 故意做的异常点
- **web 渠道下单转化率最低**（1.27%）：用于 C03「哪个渠道掉得最多」
- **美妆/服饰退货率 >8%**：用于 C05 退货率 Top5
- **大促 AOV(2378) < 前一周 AOV(2627)**：满减拉低客单价，C04 可识别高低
- **2026 大促 GMV > 2025 同期 48.0%**：C01 同比正增长
