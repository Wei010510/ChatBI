# 2. 我需要做的事情
## 第一步：准备资源（需要你自己操作，我帮不了）
买完服务器后，云厂商控制台里有「远程连接 / VNC 登录」入口，进去后逐条复制粘贴：
| 序号 | 资源 | 怎么拿 | 你给我什么 |
| ---- | ---- | ---- | ---- |
| ① | 一台云服务器 | 阿里云 / 腾讯云轻量应用服务器，新用户买 1 核 2G 够跑，约 9-19 元 / 月 | 公网 IP（如 47.100.200.50） |
| ② | Supabase 数据库连接串 | 你之前应该已经有了。如果没有：supabase.com → 免费注册 → 创建项目 → Project Settings → Database → Connection string → Pooler（host 必须是 `*.pooler.supabase.com:6543`） | Pooler 连接串完整内容 |
| ③ | LLM 三元组 | 你本地 `.env` 里的 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | 这三个值 |
| ④ | GitHub 仓库 | 如果还没推上去，把当前项目 push 到 GitHub 仓库 | 仓库地址（如 `https://github.com/xxx/ChatBI`） |


## 第二步：服务器首次初始化（需要你手动敲几条命令，我给你现成的）
买完服务器后，云厂商控制台里有「远程连接 / VNC 登录」入口，进去后逐条复制粘贴：
```text
# 1. 装 Docker + Docker Compose（一条命令搞定）
curl -fsSL https://get.docker.com | sh && systemctl enable docker && systemctl start docker

# 2. 验证装好了
docker -v && docker compose version

# 3. 把你的项目 clone 下来（替换成你的仓库地址）
git clone https://github.com/你的用户名/ChatBI.git /root/ChatBI && cd /root/ChatBI

# 4. 准备生产环境变量模板
cp .env.production .env && vim .env
# 进去后按 :wq 保存退出（填密钥的步骤我后面告诉你）

# 5. 云厂商控制台 → 安全组/防火墙 → 开 8080 和 8000 端口入站
```

## 第三步：填 .env + 首次部署
服务器上 vim .env，把 .env.production 里的占位符换成你真实的值。我给你列好要填的：
```text
# 必填 Supabase Pooler 连接串（你自己的）
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@YOUR-HOST.pooler.supabase.com:6543/postgres?pr

# 必填 LLM 三元组（你本地 .env 里的）
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_KEY=你的key
LLM_MODEL=qwen-plus

# Embedding（同 LLM 供应商就直接复制 URL 和 KEY）
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_API_KEY=你的key
EMBEDDING_MODEL=text-embedding-v4

# 功能开关（生产配置）
DATA_SCHEMA=public
MOCK_MODE=false
CLARIFY_ENABLED=true
```

填完后跑首次部署：

```text
cd /root/ChatBI
docker compose up -d --build
```
等 2 分钟，浏览器访问 http://你的服务器IP:8080，能看到 ChatBI 页面就成了！

## 第四步：Supabase 种子数据
Supabase 控制台 → SQL Editor → 按顺序执行这 3 个文件的内容：
1. `backend/data-init/01-create-data-schema.sql`
2. `backend/data-init/02-create-tables.sql`
3. `backend/data-init/03-seed-data.sql` 

## 第五步：配置自动部署（可选，不想自动部署可以跳过）
GitHub 仓库 → Settings → Secrets and variables → Actions → 新建 3 个 Secret：
| Secret 名 | 值 |
| ---- | ---- |
| SERVER_IP | 你的服务器公网 IP |
| SSH_USER | root |
| SSH_PRIVATE_KEY | 本地 `cat ~/.ssh/id_rsa` 的完整内容 |

服务器上还要跑一条（让 GitHub 能 clone）：
```text
ssh-keygen -t rsa -N "" && cat ~/.ssh/id_rsa.pub
# 把输出的公钥加到 GitHub → Settings → SSH and GPG keys
```

# 安全提醒
- `.env` 里的密钥绝对不要 commit—— 我已经在 .gitignore 里加了，并且 .dockerignore 也排除了。Docker 镜像构建不会带进密钥
- SSH 密钥只给 GitHub 存，不要发给任何人（包括我）
- 服务器安全组只开 8080（前端）和 8000（后端直连调试用），3389/22 端口只允许你的公网 IP 访问
