# 09・本地部署 + 测例跑通 Prompt（双进程 / 真实 LLM / 云端库）

> 五轮分开做，一轮人审通过后再贴下一轮。
> 轮次依赖：1 → 2 → 3 → 4 → 5；2、3 各自独立，但都依赖第 1 轮；第 4 轮依赖第 2 轮（要先有能保存的结果）；第 5 轮依赖 2、3、4 全部通过。
> **本轮全程不用 Docker / Docker Compose**。后端 `uvicorn` 直起，前端 `vite dev` 直起，数据库用已经接好的云端 Supabase（`app` + `data` schema），不本地起 Postgres。
> 硬边界：不改 `data` schema 结构与种子数据；不用 Mock 数据顶替真实链路；不在前端拼 SQL；已存报表重开只读快照，不重查、不重跑算法。

---

## 本轮目标

把「后端 + 前端」两个进程在本地拉起来，接上云端行业库、`app` 侧资源（L1 字典 / 模板 / 示例向量），用前端自然语言把 `docs/测例.md` 的测例跑一遍，确认四件事：

1. 能出正确形态的**表格 + 图表**；
2. 有**解读**；
3. 答不出来时**走澄清 / 拒答，不硬编**；
4. **报表能存、能列、重开是只读快照**。

不是做新功能，是把已有实现跑通、把跑不通的地方修到通。
