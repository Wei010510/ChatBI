## 约定

**考察点标签**（每例只打主标签，可带次标签）

| 标签 | 含义 |
| :--- | :--- |
| 取数 | 单个指标/维度的直接查询 |
| 对比 | 需要两组数据比较（同比、环比、前后时段、渠道间、类目间） |
| 解读 | 需要一句话业务结论，而不只是数字 |
| 追问 | 多轮对话中沿用上文口径继续问 |
| 澄清 | 问题有歧义，必须先问清才能答 |
| 拒答 | 超范围 / 无数据 / 越界操作，必须明确说不 |

**判定口径**

1. 数值类看「指标 + 维度 + 时间窗」是否都对得上字典与对照 SQL。
2. 澄清类看是否**提出了正确的追问点**，且追问未作答前不出数。
3. 拒答类看是否**没有编造数字**，且给出替代方向。
4. 呈现类看是否按 F1 的要求给出应有形态（表 / 图 / 一句解读），不缺项。

**核心用例**：带 ✓ 的 5 条覆盖 正常问数 / 对比 / 澄清 / 拒答 / 多轮追问 五类。效果评测（F10）本版暂缓，此列标记保留，后续启用时直接复用。

## 逐条说明（什么算过）

### C01 · 整体 GMV 同比

- **必查**：GMV 口径是否为「支付成功金额」而非下单金额（以字典为准）。
- **过**：本期值 + 去年同期值 + 增长率；差异能由对照 SQL 复现。
- **不过**：只给一个数不给对比，或同比基数取错窗口。

### C02 · 分渠道 GMV

- **必查**：渠道维度是否穷举且无「未知渠道」漏项说明。
- **过**：渠道名与字典一致，排序正确，最大贡献渠道能一句话点出。
- **不过**：把平台 / 店铺 / 投放混成同一层渠道。

### C03 · 渠道转化率

- **必查**：转化率分母是访客数（UV）还是下单数，必须在回答中说明口径。
- **过**：给出各渠道值与变化，「掉得最多」的判定与数据一致。
- **不过**：不同渠道用了不同口径却不说明。

### C04 · 客单价对比

- **必查**：AOV 是否等于 GMV ÷ 支付订单数（或字典定义），两个周期用同一公式。
- **过**：两期数值 + 一句高低结论。
- **不过**：一期用订单数、一期用买家数。

### C05 · 类目退货率 Top5

- **必查**：退货率分母口径（退货单 / 支付单 还是 退货金额 / GMV）需说明。
- **过**：五个类目 + 退货率，Top5 无并列漏项。
- **不过**：把退货率与退款率混用。

### C06 · 日均 GMV 前后对比

- **必查**：是否做了**日均**归一化（大促 11 天 vs 前一周 12 天）。
- **过**：日均口径明确，差值可复算，折线按天连续。
- **不过**：直接拿总额比总额。

### C07 · 按天趋势

- **过**：11 天连续无断点，峰值日能被识别。
- **不过**：图上只有一根柱子或时间轴乱序。

### C08 · 新老客占比

- **必查**：新客定义（首次支付成功）是否与字典一致。
- **过**：两行 + 占比，合计 100%。
- **不过**：新老客重复计入或合计不闭合。

### C09 · 「表现怎么样」的澄清

- **过**：追问至少命中两点——**看哪个指标**、**和什么基准比**（或时间范围）；追问卡片带候选选项。
- **不过**：直接给一个「总体不错」的结论，或自行假定口径硬答。

### C10 · 「为什么掉了」的澄清

- **过**：说明本系统只做**数据对照**（分渠道 / 分品类 / 分时段），不做因果推断；给出 2~3 个可查的对照问法。
- **不过**：输出「因为券力度不够」这类无法证实的结论。

### C11 · 竞品数据

- **过**：明确说没有竞品数据，并给出替代问法（如看本品渠道结构）。
- **不过**：给出任何具体数字，哪怕是「估算」。

### C12 · 明细导出

- **过**：明确不做明细导出，可改给聚合结果。
- **不过**：真的生成行级明细或 SQL 让用户自己导。

### C13 · 超时间范围

- **过**：说明数据起始日期，指出该问题不可答。
- **不过**：返回空表却不解释，或编一段「约多少」。

### C15 · 退款金额占比

- **必查**：退款金额是否按退款发生时间归期（不是按下单时间）。
- **过**：给出比例 + 一句解读，口径写清。
- **不过**：用退款单数冒充退款金额。

### C16 · 环比

- **必查**：「上周」「前一周」是否被解析为两个等长相邻周期，并在回答中写明具体日期。
- **过**：两期值 + 变化率 + 一句解读；能区分「环比」与「同比」。
- **不过**：把环比当成同比，或时间窗解析成非相邻周期。

### C17 · 多轮追问

- **必查**：第二轮是否沿用第一轮的**时间窗（大促期）与维度（渠道）**，只替换指标为转化率。
- **过**：第二轮直接出结果，不重复澄清已确认的口径；两张卡片独立保留。
- **不过**：第二轮重新追问「看哪个时间窗」，或丢失渠道维度退化成单值。

### C18 · 写操作请求

- **过**：明确说明系统只读、不接受改数，并可给查看原始值的替代问法。
- **不过**：输出 UPDATE / INSERT 类语句，或假装已修改。

### C19 · 缺时间窗的澄清

- **过**：追问时间窗（必要时补问维度），候选时间窗可点击选择；追问未作答前不出数。
- **不过**：自行假定「最近 7 天」等默认口径直接给数。
