# 前端页面交互规范

> 版本 v1.0（2026-11）｜ 适用范围：仅前端「页面设计 / 结构 / 交互 / 色调 / 组件」｜ 关联：[SDD-前端.md](./SDD-前端.md)

本文只写看得见、点得到的部分：视觉令牌、布局骨架、组件结构、交互反馈、动效与图表样式。
数据契约、接口字段、路由与状态机见 `docs/SDD-前端.md`，此处不重复。

---

## 1. 设计语言

整体气质：浅色底 + 细网格 + 青色主强调 + 靛色渐变点缀；信息密度中等，靠留白和层级区分，不靠重色块。

### 1.1 颜色令牌

所有颜色只在 `frontend/src/styles/index.css` 的 `:root` 定义一次，组件内不写死色值（图表调色板除外，见 §6）。

| 令牌 | 值 | 用途 |
| :--- | :--- | :--- |
| `--ink` | `#0f172a` | 主标题、用户气泡底、主按钮底 |
| `--ink-2` | `#1e293b` | 卡片标题 |
| `--text` | `#334155` | 正文 |
| `--muted` | `#64748b` | 次要说明 |
| `--faint` | `#94a3b8` | 占位、时间、辅助信息 |
| `--line` | `#e2e8f0` | 卡片描边、分隔线 |
| `--line-soft` | `#f1f5f9` | 弱分隔、进度条底 |
| `--bg` / `--bg-soft` | `#ffffff` / `#f8fafc` | 主区底色 / 侧栏底色 |
| `--accent` | `#0891b2` | 主强调（青），AntD `colorPrimary` |
| `--accent-strong` | `#0e7490` | 悬停加深 |
| `--accent-weak` | `#ecfeff` | 选中底色、图标底 |
| `--accent-line` | `#a5f3fc` | 选中描边、等待卡描边 |
| `--indigo` | `#4f46e5` | 渐变副色（品牌徽标、进度条） |
| `--ok` / `--ok-weak` | `#059669` / `#ecfdf5` | 在线状态、成功 |
| `--warn` | `#d97706` | 截断、同名提示 |
| `--danger` / `--danger-weak` | `#e11d48` / `#fff1f2` | 删除、错误 |

### 1.2 字体与字号

| 用途 | 字体 | 字号 |
| :--- | :--- | :--- |
| 正文 / 标题 | `--font-sans`：Plus Jakarta Sans → PingFang SC → 微软雅黑 | 13~15px，行高 1.6~1.7 |
| 数字、时间、SQL、代码 | `--font-mono`：JetBrains Mono | 10~12px |
| 页面标题 | sans，600 | 20px（`.page-title`） |
| 卡片标题 | sans，600 | 13px |

### 1.3 圆角与阴影

- 圆角：`--radius-sm` 8px（按钮、小卡）、`--radius` 12px（普通卡片、快捷卡）、`--radius-lg` 16px（结果卡、等待卡、输入框）
- 阴影四级：`--shadow-xs`（贴边）→ `--shadow-sm`（卡片默认）→ `--shadow-md`（悬停、输入框）→ `--shadow-lg`（弹层）
- 卡片一律「白底 + 1px `--line` 描边 + `--shadow-sm`」，不用重投影。

### 1.4 动效曲线

| 令牌 | 值 | 用途 |
| :--- | :--- | :--- |
| `--ease-out` | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 常规过渡、淡入 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 卡片入场（轻微回弹） |

### 1.5 光标

- `a / button / [role=button] / summary / label[for]` 统一 `cursor: pointer`（含无 `href` 的 `<a>`）
- 禁用态统一 `cursor: not-allowed`
- 可点击的行（会话项、报表行）在类上补 `cursor: pointer`
- 侧栏底部提供「智能悬浮标」开关，默认关闭，状态写入 `localStorage['smart_cursor_enabled']`；开启后在精细指针设备上隐藏系统光标，显示青色圆环 + 中心点，并叠加一层同色浅辉光。
- 悬浮标层不接收鼠标事件，不遮挡点击、输入与滚动；关闭开关或离开窗口时立即消失。触屏设备不显示悬浮标，减弱动效偏好下取消跟随延迟与辉光浮动。

## 2. 布局骨架

```
┌──────────── 280 / 64 ────────────┬────────────── 主区 ──────────────┐
│ 品牌区（渐变徽标 + ChatBI + 问数）│ 对话页 / 报表列表 / 报表详情      │
│ 新建对话                          │                                  │
│ 搜索历史对话                      │  头部 56px（半透明 + 模糊）       │
│ 对话 / 报表 导航                   │  内容区（最大 860px 居中）        │
│ 历史会话列表（可滚动）             │  底部输入区（固定）               │
│ 脚注：数仓状态 + 用户              │                                  │
└──────────────────────────────────┴──────────────────────────────────┘
```

| 区域 | 尺寸 / 规则 |
| :--- | :--- |
| 侧栏 | 展开 280px，折叠 64px；宽度过渡 0.25s；`--bg-soft` 底 + 右侧 1px 描边 |
| 顶栏 `.chat-header` | 高 56px，`rgba(255,255,255,.9)` + `backdrop-filter: blur(8px)`，底部 1px 描边 |
| 对话内容 `.message-list` | 上下 padding 24/8、左右 32；子元素最大 860px 居中；纵向间距 20px |
| 输入区 `.chat-input-wrap` | 底部吸底，向上渐隐白底；输入框最大 860px |
| 报表页 `.page-wrap` | 内容最大 960px，标题 + 副标题 + 操作按钮一行 |
| 快捷卡区 | 两列网格，最大 640px，间距 10px |
| 背景纹理 | 白底 + 36px 细网格（`rgba(15,23,42,.035)` 横竖各 1px） |
| 响应式断点 | ≤900px：侧栏与内边距收窄，快捷卡改单列；不做完整移动端适配 |

## 3. 页面与组件

### 3.1 侧栏（AppLayout）

| 区块 | 内容 | 交互 |
| :--- | :--- | :--- |
| 品牌区 | 渐变徽标（青→靛）+ `ChatBI` + 小徽章「问数」 | 折叠按钮切换 280/64px，图标切换展开/收起 |
| 新建对话 | 深色通栏按钮 + 加号 | 点击清空当前会话指针并回到对话页 |
| 搜索 | 放大镜 + 输入框，占位「搜索历史对话…」 | 按标题**本地**过滤，不发请求；无结果显示「暂无匹配对话」 |
| 导航 | 「对话」「报表」两枚 pill | 当前路由高亮；折叠时只留图标 |
| 历史会话 | 标题「历史会话」+ 右侧「清空」+ 会话项列表 | 会话项显示标题 + 等宽时间；hover 出删除图标；点击切换会话；删除/清空均二次确认 |
| 脚注 | `数据仓库` + 「已连接」chip；其下为「智能悬浮标」开关；底部为用户头像「用」+ 「用户」 | 悬浮标开关显示「开启 / 关闭」，点击切换全局圆形悬浮标与浅辉光；用户位无点击行为，作为鉴权占位 |

### 3.2 对话页（ChatPage）

| 状态 | 结构 |
| :--- | :--- |
| 顶栏 | 左：`智能问数` + 副标题「自然语言查询 · 自动出表出图」；右：状态胶囊（绿点 + 数据仓库在线） |
| 欢迎态（空会话） | 渐变描边圆角方图标（白内衬 + 青色火花，上下浮动）→ 标题「今天想了解什么数据？」→ 两行说明 → 4 张快捷卡 |
| 消息流 | 每条消息上方一行 meta：`我 / ChatBI` + `HH:mm`；用户为深色气泡（右下 4px 小圆角），助手为白色结果卡（左上 4px 小圆角） |
| 加载会话 | 标题 meta「正在加载会话…」+ 骨架卡（3 条流光细线 + 1 块内容区） |
| 等待回答 | 一张等待卡：渐变方块图标脉冲 + 「正在理解问题、生成 SQL 并执行…」+ 4px 流光进度条 + 「复杂问题约需 40~90 秒，结果会自动出现」+ 取消按钮 |
| 输入区 | 可选「智能联想」chip 行 + 输入框 + 发送/停止按钮 + 底部提示 |

快捷卡（4 张，固定文案）：

| 标签 | 问题 |
| :--- | :--- |
| 渠道表现 | 最近一周各渠道 GMV 是多少 |
| 转化效率 | 最近一周的 ACOS 是多少 |
| 商品退货 | 本月退货率最高的 5 个类目 |
| 用户结构 | 新老客 GMV 占比 |

### 3.3 结果卡（ResultCard / ResultBody）

- **卡头**：图标 + 「查询结果」+ 行数 chip（`N 行`）+ 图表类型 chip（柱状图 / 折线图）+ 右侧「存为报表」按钮（无数据时禁用）
- **数据表**：AntD Table，`size=small`，列宽 140，纵向滚动 300px；超过 10 行分页；数值按比率/千分位格式化，空值显示 `—`
- **截断提示**：超过 1000 行时顶部黄色 Alert「结果超过 1000 行，仅展示前 1000 行」
- **可视化**：小标题（柱/线图标 + 「可视化」）+ `.chart-frame` 内嵌 ECharts
- **解读**：灯泡图标 + 一句话结论（`.narrative-line`）
- **空数据**：蓝色 Alert「该条件下暂无数据 / 可尝试调整时间范围或更换分析维度」

### 3.4 澄清卡 / 拒答卡 / 错误卡

| 组件 | 结构 | 交互 |
| :--- | :--- | :--- |
| ClarifyCard | 图标头 + 问题 + 选项按钮 + 自由输入 | 点选项或提交文本即补全提问；卡片失效后选项置灰并提示重新提问 |
| RejectCard | 图标头 + 拒绝原因 + `reason_code` chip + 建议 pill | 技术类/业务类用不同颜色与图标区分；建议项点击后填入输入框 |
| ErrorBubble | 红色系图标头 + 「请求失败」+ 文案 + 「重试」 | 点重试按原问题重发 |

### 3.5 报表列表与详情

| 页面 | 结构 | 交互 |
| :--- | :--- | :--- |
| ReportsPage | 标题「报表」+ 副标题 + 「新建查询」按钮；空态卡片（Empty + 去提问）；有数据时 `.surface` 包表格 | 表格列：名称 / 来源问题 / 保存时间（等宽字体）/ 操作；每页 20 条 |
| ReportTable | 行内改名、行尾删除 | 点名称或整行打开详情；铅笔进入行内编辑（Enter 确认、Esc 取消、失焦保存）；删除二次确认「删除后不可恢复」；hover 行底色变化 |
| ReportViewPage | 面包屑「报表 / 名称」+ 结果卡 + 「只读快照」chip + 来源问题 | 只读：无提问、无刷新；404 显示「报表不存在」+ 返回列表 |

### 3.6 登录占位

无登录需求，`/login` 只保留一张居中卡片：渐变描边图标 + 「本版无需登录」+ 说明 + 「进入对话」主按钮。

└─ 主区

## 4. 交互规范

### 4.1 状态反馈

| 状态 | 规则 |
| :--- | :--- |
| hover | 卡片上浮 1~2px / 描边变青 / 阴影加深；列表行右移 2px；按钮上浮并加深底色 |
| active（按下） | `scale(0.94~0.98)`，去掉阴影 |
| selected（当前项） | 青色浅底 + 青色描边；会话项左侧 3px 青色竖条（高度动画） |
| focus | 输入框聚焦：上浮 1px + 4px 青色光晕；键盘焦点用 `:focus-visible` 出 2px 描边环，鼠标点击不出环 |
| disabled | 透明度 0.35 + `not-allowed`；主按钮禁用时不响应 hover |
| 折叠态 | 侧栏只留图标，文字、搜索、时间全部隐藏，避免挤压 |

### 4.2 加载与反馈

- 切换会话：点击瞬间高亮 + 骨架屏，不等接口；连续快速切换按请求序号丢弃过期响应。
- 等待回答：等待卡展示进度条与预计时长，可随时取消（等同中止请求）。
- 请求超时：`ask / clarify` 超时 300s，提示「请求超时」并保留用户气泡，不静默删除。
- 后台刷新：会话列表刷新不阻塞消息区渲染。
- 删除/清空：均需 Popconfirm 二次确认，文案明确「不可恢复」。

### 4.3 键盘

| 操作 | 行为 |
| :--- | :--- |
| Enter | 发送 |
| Shift + Enter | 换行 |
| Esc（报表改名） | 取消编辑 |
| Enter（报表改名） | 确认改名 |
| Tab | 按视觉顺序聚焦，聚焦环仅在键盘操作时出现 |

### 4.4 滚动

- 新消息或等待态出现时，消息区平滑滚到底部。
- 滚动条 6px，滑块 `rgba(148,163,184,.4)`，hover 加深；表格与侧栏各自独立滚动。

## 5. 动效规范

| 场景 | 规则 |
| :--- | :--- |
| 卡片入场 | 从下往上浮入：`translateY(28px) → 0`、透明度 0 → 1、`scale(.985) → 1`；0.48s，`--ease-spring` |
| 快捷卡 | 同上，4 张依次延迟 0.04 / 0.11 / 0.18 / 0.25s |
| 用户气泡 / 等待卡 / 骨架卡 | 0.38~0.42s 上浮淡入 |
| 消息整体 | 淡入 0.25s |
| 欢迎徽标 | 3.4s 循环上下浮动 6px（`ease-in-out`） |
| 等待图标 | 1.8s 缩放脉冲（1 → 1.06） |
| 进度条 | 1.5s 从左到右流光循环 |
| 骨架屏 | 1.4s 线性流光（背景位置 -100% → 100%） |
| 智能悬浮标 | 圆环轻微滞后跟随指针，浅青色辉光更慢跟随并以 2.8s 周期轻柔浮动；按下时圆环缩至 0.82 倍 |
| 悬停/按下 | 0.15~0.2s，只改颜色/位移/阴影，不做布局抖动 |

实现约定：

- 入场动画一律 `animation-fill-mode: backwards`，动画结束不占用 `transform`，避免覆盖 hover 位移与按下缩放。
- 动画只用于「出现」和「操作反馈」，不做页面级转场、不做无限装饰动画（欢迎徽标、等待态与已开启的悬浮标辉光除外）。
- 悬浮标通过 `requestAnimationFrame` 直接更新固定定位层的 `transform`，不在每次指针移动时触发 React 重渲染。
- `@media (prefers-reduced-motion: reduce)` 下关闭全部动画与过渡（时长压到 0.01ms）。

## 6. 图表规范

| 项 | 规则 |
| :--- | :--- |
| 调色板 | `#0891b2`、`#4f46e5`、`#f59e0b`、`#10b981`、`#f43f5e` |
| 柱状图 | 圆角 `[6,6,0,0]`，最大宽度 42px；折线图平滑曲线 + 青色渐变面积 |
| 坐标轴 | 网格线 `#f1f5f9`，轴线隐藏；标签 11px `--muted` |
| tooltip | 深色半透明 `rgba(15,23,42,.92)`，白字，圆角 8 |
| 图例 | 仅多系列时显示，置于底部 |
| 自适应 | 监听容器 `resize` 重绘；`chart === null` 或 rows 为空时不渲染图表，只出空态 |
| 颜色来源 | 前端固定调色板，不读后端颜色字段 |

## 7. 文案与空态

| 位置 | 文案 |
| :--- | :--- |
| 顶栏 | 智能问数 · 自然语言查询 / 自动出表出图 · 数据仓库在线 |
| 欢迎标题 | 今天想了解什么数据？ |
| 欢迎说明 | 直接用中文提问，我会自动选表、生成 SQL、出表出图，并给一句解读。/ 不用记字段名，也不用写 SQL。 |
| 输入占位 | 问点什么，比如：上周各渠道 GMV 是多少 |
| 输入提示 | 回车发送 · Shift + 回车换行 · 结果基于真实数据仓库 |
| 等待提示 | 正在理解问题、生成 SQL 并执行… / 复杂问题约需 40~90 秒，结果会自动出现 |
| 会话空态 | 暂无匹配对话 |
| 报表空态 | 还没有保存的报表 → 去提问 |
| 会话删除确认 | 删除这个会话？会话内的消息会一起删除，不可恢复。 |
| 清空确认 | 清空全部会话？所有会话及其消息都会删除，不可恢复。 |

## 8. 明确不做（前端侧）

- 完整移动端适配（只做 ≤900px 收窄）
- 用户可切换主题 / 深色模式（设计令牌统一，但不提供切换入口）
- 国际化
- 逐 token 流式输出、打字机效果
- 页面级路由转场动画
